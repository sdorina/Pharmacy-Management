PHARMACARE - PHARMACY MANAGEMENT SYSTEM

HOW TO RUN (Windows + VS Code)
1. Extract the Pharmacy-Management folder from the ZIP.
2. Open VS Code.
3. Choose File > Open Folder, then select the extracted Pharmacy-Management folder.
4. Choose Terminal > New Terminal.
5. Type this command and press Enter:
   npm.cmd install
   Wait until installation finishes.
6. Type this command and press Enter:
   npm.cmd run dev
7. Open the local address Vite displays, usually http://localhost:5173/

IMPORTANT:
- Keep the terminal running while you use the app.
- To stop it, click the terminal and press Ctrl+C.
- Medicines are stored temporarily in memory. They reset when the server restarts.
- This is a learning/demo project, not a real pharmacy dispensing system.
- It does not verify prescriptions or provide medical advice.
